Proyecto de Ingeniería Web para implementar el proyecto de prácticas de la asignatura.

# Gestión del Concurso y Archivo Histórico del Carnaval de Cádiz
Plataforma web de código abierto desarrollada en el marco de la asignatura **Ingeniería Web** (Grado en Ingeniería Informática, Universidad de Cádiz, curso 2026/2027).

## Descripción
El sistema consta de dos áreas principales:
- **Front-office:** Portal público para aficionados, prensa e investigadores con información de la edición en curso, fichas de agrupaciones, calendario de sesiones, repertorios y archivo histórico.
- **Back-office:** Herramientas internas de gestión para personal municipal, jurado y agrupaciones (ediciones, inscripciones, sorteos, puntuaciones, catalogación histórica y roles).
